# Ryan Bertschinger

Quantitative developer at [Ironclad Asset Management](https://ironcladam.com), a systematic alternatives manager in Johannesburg, where I build and run the firm's data platform end to end. Computer Science and Financial Risk Management graduate.

## What I work on

- **Data platform:** a SQL database on Azure, the scheduled pipelines that land market, broker and fund-administrator data into it, and the internal application programming interface (API) that serves it.
- **Applications:** internal dashboards and the firm's public website, built in SvelteKit.
- **Infrastructure and delivery:** Terraform and Bicep, continuous integration and deployment (CI/CD) on Azure DevOps, and monitoring.
- **AI tooling:** Model Context Protocol (MCP) servers that give coding agents read-only, self-documenting access to the firm's data and code, plus the agent setup and evaluations the whole firm works with.

That work lives in a private Azure DevOps monorepo, so it doesn't show up here.

Stack: Python, T-SQL, TypeScript, SvelteKit, Azure, Terraform.
